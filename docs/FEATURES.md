# easy-oa 功能清单与实现计划

> easy-oa 是一套面向中小团队的轻量 OA（办公自动化）系统，技术栈与 easy-mall 保持一致：
> 后端 Java 25 + Spring Boot 4.1.2 + MyBatis-Plus + MySQL（管理端 Spring Security + JWT），
> 前端 Vue3 + Vben Admin（Element Plus），预留小程序端（uni-app）扩展。
>
> 仓库结构：
> ```
> easy-oa/
> ├── backend/            # Maven 单体多模块（当前：easy-oa-admin，端口 8091，context-path /oa）
> ├── db/                 # easy_oa.sql 建库脚本 + migrations/ 幂等增量迁移
> ├── docs/               # 设计文档
> └── web-admin/          # 管理后台前端（规划中，vben web-ele 同款结构）
> ```

## 分期与功能清单

### Phase 1：系统底座 + 系统管理（✅ 本期落地）

| 模块 | 功能 | 状态 |
| --- | --- | --- |
| 基础设施 | 统一 Result/PageResult 响应、全局异常、TraceId、审计字段自动填充、乐观锁、逻辑删除、操作日志 AOP | ✅ |
| 登录认证 | 账号密码登录（JWT 无状态）、登录防爆破锁定（5 次锁 15 分钟）、登录日志、当前用户信息 | ✅ |
| 员工管理 | 部门树归属、增删改查、启用/禁用、重置密码、角色分配 | ✅ 后端 |
| 部门管理 | 树形部门、增删改查 | ✅ 后端 |
| 角色管理 | 角色增删改查、菜单/按钮授权 | ✅ 后端 |
| 菜单管理 | 树形菜单（catalog/menu/button/link/embedded），动态路由下发 | ✅ 后端 |
| 日志审计 | 操作日志（AOP 自动采集）、登录日志查询 | ✅ 后端 |
| 管理后台前端 | vben web-ele 同款前端，动态菜单 + 上述页面 | ⏳ 下一阶段 |

### Phase 2：审批中心（OA 核心）

| 模块 | 功能要点 |
| --- | --- |
| 审批模板 | 模板管理（请假/报销/采购/用章/出差等）；表单字段自定义；审批节点配置：逐级审批 / 指定人 / 会签（全部同意）/ 或签（任一同意）；条件分支（如金额 > 5000 加签财务总监） |
| 审批发起 | 按模板发起，表单渲染 + 校验；附件上传；自动带出发起人部门/直属上级 |
| 审批流转 | 状态机：草稿 → 审批中 → 通过 / 驳回 / 撤回 / 转交；节点待办列表；同意/拒绝/转交/加签/催办 |
| 我的单据 | 待我审批、我已审批、我发起的、抄送我的 |
| 审批快照 | 表单与节点流转快照落库（含每节点操作人、时间、意见） |
| 消息通知 | 站内消息（新待办、通过、驳回）；预留订阅消息/邮件通道 |

### Phase 3：行政办公

| 模块 | 功能要点 |
| --- | --- |
| 公告通知 | 发布/撤回/置顶/有效期；已读回执与统计；全员/按部门范围投放 |
| 会议室预约 | 会议室档案（容量/设备）；按日历预约与冲突检测；取消与使用记录 |
| 资产管理 | 固定资产/办公用品台账；领用/归还/转移流转记录；报废 |
| 用车/用章 | 申请单走审批流，登记台账 |

### Phase 4：考勤人事

| 模块 | 功能要点 |
| --- | --- |
| 考勤规则 | 班次/打卡规则（上下班时间、弹性分钟数、节假日/调休日历） |
| 考勤打卡 | 每日打卡记录、迟到/早退/缺卡判定 |
| 假期管理 | 假期类型与余额（年假/事假/病假等）；请假关联 Phase 2 审批流，通过后扣减余额并回写考勤 |
| 加班/补卡 | 加班申请（关联审批）、补卡申请与审核 |
| 考勤报表 | 个人/部门月度汇总，异常明细导出（xlsx） |

### Phase 5：日程与文档

| 模块 | 功能要点 |
| --- | --- |
| 个人日程 | 日程/待办 CRUD、重复规则、提醒；周/月视图 |
| 共享日历 | 部门共享日历、会议室占用视图 |
| 文档中心 | 知识库目录树、文档编辑（富文本）、阅读权限（部门/角色/指定人） |
| 全文检索 | 公告/文档/审批单标题与内容检索 |

### Phase 6：工作台与增强

| 模块 | 功能要点 |
| --- | --- |
| 工作台 Dashboard | 待办审批数、今日考勤概览、最新公告、我的日程、常用入口 |
| 数据统计 | 审批效率（平均耗时）、部门考勤排名等看板 |
| 小程序端 | uni-app 同款栈：移动端审批（待办/发起/详情）、打卡、公告浏览 |
| 开放能力 | Webhook/消息推送对接企业微信/钉钉群机器人 |

## 约定

- 数据库变更一律走 `db/migrations/YYYYMMDD_xxx.sql` 幂等增量脚本，建库脚本 `db/easy_oa.sql` 仅在新环境初始化用。
- 权限码分段：`system:xxx`、`approval:xxx`、`office:xxx`、`attendance:xxx`、`schedule:xxx`、`doc:xxx`，新增后端校验必须同步登记 `PermissionCodes` 与菜单表。
- 后端模块按 easy-mall 风格：`modules/<域>/controller|service|dto|vo` + 顶层 `entity/mapper`。
